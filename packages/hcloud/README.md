# @vyft/hcloud

Hetzner Cloud provider for vyft. Implements the `@vyft/platform` module shape.

## Usage

```ts
import hcloud from "@vyft/hcloud";
```

## Resources

| Resource | Description |
|----------|-------------|
| `network` | Hetzner Cloud network with subnet |
| `server` | Hetzner Cloud server |

## Secrets

| Name | Description |
|------|-------------|
| `apiToken` | Hetzner Cloud API token |
